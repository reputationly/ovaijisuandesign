## 三条最容易踩的坑（都已踩过，别再踩）

1. **基准版本**：`~/ov-golden-ref` 是 **4.0.0**，拿它比 4.0.3 会得出相反结论。
   4.0.3 基线在 `~/ov-golden-ref-4.0.3`（37 屏，`referenceVersion: "4.0.3"`）。
2. **搜参照要搜全部 chunk**：`assets/` 下有 358 个懒加载 chunk，
   只搜主 bundle 会把懒加载里的东西误判为"参照没有"。
   用 `node scripts/refdiff/refgrep.mjs <字符串>`。
3. **动手前先确认"是不是已经有了"**：本会话两次差点重写已存在的组件
   （WorkflowsPage 656 行、HomeProjectPicker 156 行）。

## 三个已勘定、待实施的缺口

### A. 首页项目托盘（home 14.72% / home-skill-inspiration 14.76%）
**已试过三种挂载位置，都不如不挂**（详见 `4.0.3-home-project-picker-plan.md`）。
结论：**必须先改卡片尺寸关系，再插托盘**，否则每插一次把下方推低 42px。
可复用的已实现：`MessageInputBase.footerSlot`、`HomeProjectFolderIcon`、
`HomeProjectPicker`（已存在）、托盘完整类名。

### B. 7 屏共同的 ~3.1%（ws-a / ws-b / ws-markdown / ws-zoom / ws-pdf / ws-multi-angle / ws-relight）
**已排除"缺结构"**：按 ui-id 容器的子树规模比对，差全部为 ±1（即叶子节点）。
所以是**样式层面**（字号/行高/间距/圆角/渐变）或文字细节。
下一步方法：**两侧按同名 ui-id 各采样计算样式并比对**（需写 CDP 采样脚本），
而不是继续比 DOM。

### C. 补录 3 屏基线
`project-assets` / `project-created` / `settings-platform` 仍未录。
单屏录制偶发卡在「等待 ws-a 会话焦点持久化」，重试即可。
