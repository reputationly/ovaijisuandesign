# 4.0.3 → 4.0.4 差异报告（只读，第 1 步产物）

**生成方式**：`node scripts/refdiff/upgrade.mjs --from 4.0.3 --to 4.0.4`
**产物**：`.probe/upgrade/4.0.3-to-4.0.4/`（`REPORT.md` / `REPORT.json` / `delta.md` / `delta.json` / toplevel 表）
**只读**：未修改任何参照快照，未动产品代码。

## 一、一个重要发现：4.0.4 把主体 chunk 改名了

| 版本 | 入口（`index.html` 引用） | 主体（最大可达块） |
|---|---|---|
| 4.0.3 | `index-B3Ss5vz1.js`（22,270,553 B） | 同入口 |
| **4.0.4** | **`index-6QHLViCD.js`（489 B，引导脚本）** | **`mermaid-GHXKKRXX-DuPXfUYG.js`（22,515,007 B）** |

**4.0.4 的入口变成了 489 字节的引导脚本，真正的 22 MB 主体被 vite 按主导模块命名成
`mermaid-*.js`。** 如果仍按「`index-*.js` 就是主 bundle」的假设去比，
会得到 `same: 0 / onlyOld: 21404` 这种荒谬结果（我第一次跑就是这样）。

**已修正**：`scripts/refdiff/lib/refs.mjs` 改为从 `index.html` 读入口，
再沿 `from "./x.js"` / `import("./x.js")` 收集可达文件、取**最大的一块**作为主体。

## 三、上游新增、我们完全没有的（跟进候选）

**界面 id（22 个）**——集中在四个新功能：

- **音频裁剪**：`audio-trim-cancel` / `-confirm` / `-play` / `-playhead` / `-selection`
- **视频裁剪**：`video-trim-cancel` / `-confirm` / `-play` / `-playhead` / `-selection`
- **视频抽帧**：`video-frame-capture-cancel` / `-capture` / `-confirm` / `-play` / `-track`

- **外部 Agent 全选**：`external-agent.models-select-all` / `.projects-select-all` / `.setup.creation-hint` / `.setup.manual`

**事件（24 个）**：全部是 `hilo:canvas-v3:*` 观测埋点（`doc-fetch`、`first-image-ready`、
`images-settled`、`selection-projection`、`zoom-long-frames` …）。

**i18n（40 个）**：对应上面几个新功能的文案（`canvas.audioTrim.*`、`canvas.videoTrim.*`、
`canvas.frameCapture.*`、`debugPanel.logLevel.*`、`settings.externalAgent.*`）。

**从上游消失的（3 个 id）**：`canvas-v3.html-preview`、`external-agent.credit-reminder`、
`external-agent.credit-threshold`。
