每一条都必须写明理由、并在这里追踪到修复为止。

## 1. `canvas.node-promote-to-asset`（4 屏）

- **出现屏**：ws-video / ws-audio / ws-text-editor / ws-select-image
- **现象**：我方 `oursOnly`
- **证据**：
  - 参照基线这 4 屏的 DOM 里**没有任何节点操作条**：
    无 `canvas.audio-node`、无 `canvas.image-tool.*`、无 `canvas.node-promote-to-asset`
  - 我方同屏渲染了完整一排：
    `canvas.audio-node` / `canvas.audio-node.toggle-play` / `canvas.audio-node.download` /
    `canvas.image-tool.clip` / `canvas.image-tool.extract-audio` / `canvas.node-promote-to-asset`
- **推断**：参照的节点操作条**只在选中或悬停时出现**，我们的是**常显**
- **性质**：真实行为差异，**不是**无害结构差异
- **修复方向**：查参照 `CanvasV3AudioToolbar` 的挂载条件（是否受 selection / hover 控制），
  把我们的改成同样条件
- **修好后**：删除 `expected-diffs.json` 里这 4 屏的登记与该说明
