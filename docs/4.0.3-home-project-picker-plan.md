## 关键结构（照参照）

### 托盘容器
```jsx
<div className="home-composer-project-tray relative z-0 flex min-h-10.5 w-full items-end
                rounded-b-[var(--home-input-radius)]
                px-[calc(var(--message-input-card-padding)+var(--home-input-border-width))] pt-1 pb-1.5"
     data-action-ui-id="home-project-tray">
  <HomeProjectPicker presentation="tray" selectedProjectId={...} disabled={...} onChange={...} />
</div>
```

### 触发按钮（tray 形态）
```jsx
data-action-ui-id="home-project-btn"
className="no-drag inline-flex h-8 min-w-0 max-w-60 cursor-pointer items-center
           gap-[var(--home-input-control-content-gap)] px-2
           text-[length:var(--home-input-toolbar-font-size)] font-normal
           text-foreground/70 transition-colors group-hover/project-picker:bg-[var(--message-input-control-hover)]
           hover:text-foreground disabled:opacity-50 rounded-full"
```
- 左侧图标槽 `size-4`：team 项目用 `Users`，其它用 `HomeProjectFolderIcon`
- 有选中项目且未禁用时，hover 会让图标淡出、露出"清除"按钮
  （`group-hover/project-picker:opacity-0` + `home-project-clear`）

### 下拉
```jsx
<ActionDropdownMenuContent align="start" side="bottom" sideOffset={8}
    collisionAvoidance={{ side: "none", align: "shift" }}
    className="min-w-52 max-w-80 overflow-hidden"
    data-action-ui-id="home-project-menu">
  <div data-action-ui-id="home-project-list"
       className="home-project-list flex min-h-0
                  max-h-[calc(var(--action-list-item-height)*5.5+var(--action-list-row-gap)*5)]
                  flex-col gap-[var(--action-list-row-gap)] overflow-y-auto overscroll-contain">
    {projects.map(p => (
      <ActionDropdownMenuItem data-action-ui-id="home-project-option" data-project-id={p.id}
                              onClick={() => onChange(p.id)}>
        {p.kind === "team" ? <StrokeIcon icon={Users} size={16}/> : <HomeProjectFolderIcon/>}
        <span className="min-w-0 flex-1 truncate">{p.name}</span>
        {selectedProjectId === p.id ? <StrokeIcon icon={Check} size={14}/> : null}
      </ActionDropdownMenuItem>
    ))}
  </div>
  <ActionDropdownMenuSeparator/>
  <ActionDropdownMenuItem data-action-ui-id="home-project-create"
                          onClick={() => setCreateDialogOpen(true)}>
    <StrokeIcon icon={Plus} size={16}/><span>{t("project.create.trigger")}</span>
  </ActionDropdownMenuItem>
</ActionDropdownMenuContent>
```

### 切换项目时的进入动画
```js
if (projectSwitch) {
  enter(composer.querySelector(".home-project-greeting"), 180, 0, 0.82);
  enter(composer.querySelector('[data-action-ui-id="home-project-btn"]'), 180, 0, 0.82);
} else {
  enter(composer, 320);
  enter(page.querySelector(".home-media-showcase-block"), 320);
}
// duration, delay, startOpacity；缓动 cubic-bezier(0.22, 0.61, 0.36, 1)，fill: backwards
```
`reducedMotion.addEventListener("change", cancel)` —— 偏好变化时取消进行中的动画。
