## 第一批补丁：只有 `<title>` 一条

```js
{ id: "v3-title", file: "index.html",
  find: "<title>MiniMax Design V3</title>",
  replace: "<title>蒜狸小助手</title>", count: 1 }
```

**为什么只这一条**：4.0.4 的 v3 产物里 `MiniMax Design` 只出现这 1 次；
其余 `MiniMax` 全是模型 id / 模型名 / 后端取值（`MiniMax-H3`、`backend:"minimax_v3"`），
属于接口值，不能替换。v3 里也没有 logo / 字标文件。

**`bundle.ts` 的语义**（已核对源码）：

本方案重生成时保留原条目列表只重算 sha256，与它一致。

   脚本会显式报错而不是静默用旧产物。
