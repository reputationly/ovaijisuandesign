### 诊断方法（有效的二分）

### 根因：一串 TDZ

`canvas-area-v3.js` 在求值期就会碰到**声明在使用之后**的 `const/let`：

| # | 符号 | 位置 |
|---|---|---|

| 2 | `powers` | `canvas-v3-model.js` 5708 声明、5534 的 `increment()` 使用 |
| 3 | `Context$3` | `ui-components.js` 9089 声明、2541 使用 |
| 4 | `TableFullscreen$1` | 11166 声明、5150 使用 |
| 5 | `IMAGE_TOOLS` | 35720 声明、11159 展开使用 |

**每修一个，错误就前进一个** —— 说明这是一条链。

### 修好的部分（已验证）

- TDZ #1 修好后：`ws-a-v3` **6.242% → 5.500%**
