## 五、对「从源码构建」的意义

1. **v3 的 5 个路由里，3 个（assets/structure/execution）在主 chunk 内、2 个是 lazy chunk。**
   要自己打出等价产物，需要有这 5 个视图的组件。
2. **画布视图（`/canvas`）的基础已经在我们源码里**（`canvas-v3/`、`canvas/`、`media-editing/`），
   但 `CanvasPage` chunk 里仍有 132 个 id 我们没有 —— 主要是上表 A 类（批注、播放器控制、
   全景、模型浮层）与 B 类的少数。
3. **聊天视图（`/chat`）几乎是从零**：`ChatPage` chunk 的 14 个 id 只有 2 个在我们源码里。
4. **`EditorInterface` chunk 的 13 个 id 一个都不在我们源码里**，但我们有
   `export-engine/editor-interface.js`（69,056 行）—— **需要先确认它是不是同一份实现**
   （id 可能是 v3 版本新加的）。
