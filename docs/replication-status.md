# 复刻现状：哪些是原样用参照的，哪些是我们重写的

对照 MiniMax Design 3.0.16，写于 2026-09-26，同日更新（gateway 本地可用路由补齐之后）。参照原文都在 `reference/3.0.16/`。

> 参照版本已升到 **3.0.21**（2026-10-01）：界面改从 `reference/3.0.21/app/out/renderer` 拷，
> 补丁 64 条；`reference/3.0.16/` 和 `3.0.20/` 留着对照。下文提到 3.0.16 的地方，
> 除版本号本身外结论未变（gateway / mcp-tools / 插件 / agent 配置在 3.0.20 → 3.0.21 之间没动）。

三种来源：

- **原样**：直接用参照的文件（编译产物或原文），不改或只打补丁。行为和参照一致。
- **重写**：我们自己写的代码，接口（路由、字段、通道名、返回形状）对齐参照，实现是我们的。
- **替换 / 不做**：参照连的是它自己的云端，我们换成自己的平台或本地默认值；或者属于范围外。

## 〇、按来源三分（2026-09-26 逐项核对）

### A. 和参照一模一样（原文拷过来，逐字节核对过）

| 接口面 | — | gateway 路由路径、IPC 通道名（白名单 162 个）、项目包格式、`canvas.json` 格式与参照一致 |

### B. 直接用编译产物

| 部分 | 位置 | 说明 |
|---|---|---|
| **界面（渲染层）** | `reference/3.0.21/app/out/renderer` → 构建时拷到 `app/desktop/out/official-ui` | 唯一在运行时直接用的编译产物；打 64 个补丁（`app/official-ui/patches.mjs`） |

`reference/3.0.16/` 里的 gateway、mcp-tools、opencode 插件、主进程也是编译产物，但**只作对照参考，运行时不用**。

### C. 有差异的地方

**我们重写的（接口对齐参照，实现是我们的）**

| 部分 | 参照 | 我们 | 差距 |
|---|---|---|---|
| preload | 约 6000 行 | 约 370 行 | 暴露的对象和通道一致；登录固定为本机用户；内置浏览器不暴露 |
| 主进程 | 约 29 万行（含第三方） | 约 1 万行（含 preload） | 编排对齐；范围外服务给形状正确的空实现 |
| gateway | 466 条路由 | 约 2.4 万行，258 条 | 范围内的已补齐；208 条是范围外或暂缓 |
| MCP 工具 | 54 个 | 约 1.5 万行，33 个 | 21 个没注册（ComfyUI、浏览器、插件 agent、资产中心、语音识别、抠图） |
| opencode 插件 | 约 20 个模块 | 6 个模块，约 450 行 | **范围内差距最大的一块**：缺 skill 授权、模型目录提示、上下文压缩续写、权限日志、附件等 |
| `opencode-plugin-trace` | 有 | 没有 | 遥测，不做 |

**界面补丁改掉的（58 个）**：品牌（名字、logo、字标、窗口标题）；登录 / 营销 / 推广弹窗；隐藏内置浏览器、ComfyUI、自定义模型、使用指南外链；首页示例素材放行本地地址、允许无视频的图片卡；对话模型选择器去掉写死的白名单。

**行为上故意不同的**

| 项 | 参照 | 我们 |
|---|---|---|
| 生成后端 | 自家云端 + 各厂商 | 自建平台；出图 `qwen-image-pro-enhanced`、视频 `minimax-h3-2k` / `minimax-h3-ref-2k`（聚合编排），对话 `qwen3.8-flash-fp8` |
| 模型目录 | 云端下发 | 本机配置生成，挂在参照的厂商名下；聚合视频的参数照 new-api `docs/hilo-catalog.json` |
| 编辑能力 | 全 | 语音识别、抠图、口型、擦字幕、音频分离、图层拆分、人声分离平台没有，返回"当前平台不支持" |
| 账号 / 团队 / 计费 | 云端 | 固定本机用户、个人空间、不计费 |
| 云端配置、弹窗、推广、技能市场、图片搜索、CDN 上传 | 云端 | 本地默认值 / 空结果；技能市场只列自带的 36 个 |
| 首页创作灵感 | 云端下发，带演示视频 | 参照内置的三组示例，去掉了我们没有的技能绑定，素材本地提供 |
| 数据目录 | `~/Movies/Hub`、`~/.hub` | `~/Movies/蒜狸小助手`、`~/.ovhub`（不和同机的参照应用互相覆盖） |
| 不做 / 暂缓 | — | 登录、团队、计费、ComfyUI、内置浏览器、插件、自定义模型；资产中心、反馈、水印暂缓 |
| 打包、自动更新 | Velopack | 还没做（M10） |

## 一、总表

| 部分 | 参照 | 我们 | 来源 | 对齐程度 |
|---|---|---|---|---|
| **界面（渲染层）** | `app.asar` 的 `out/renderer`，约 51 万行（含第三方库） | 同一份编译产物，构建时打 58 个补丁（`app/official-ui/`） | **原样 + 补丁** | 界面代码和参照一致；补丁只改品牌、去登录 / 营销弹窗、隐藏浏览器和 ComfyUI 入口 |
| **preload** | `out/preload/index.mjs`，约 6000 行 | `app/desktop/src/preload/index.ts`，约 370 行 | 重写 | 暴露的对象和通道白名单与参照一致；登录固定为本机用户；内置浏览器不暴露 |
| **主进程** | `out/main`，约 29 万行（含第三方库） | `app/desktop/src/main`，约 8700 行 | 重写 | 编排（gateway / opencode 拉起、多工作区、身份、恢复）对齐；约 165 个 IPC 通道里核心的都按参照形状实现，范围外的给形状正确的空实现 |
| **gateway** | `gateway/dist/main.js`，NestJS，466 条路由 | `app/gateway`，NestJS，约 1.3 万行 | 重写 | **258 / 466** 条路由。**范围内的已全部补齐**；剩下 208 条是范围外（团队、账号、计费、技能市场运营、云端项目、ComfyUI、插件、浏览器、遥测）和暂缓的资产中心 / 反馈 / 水印，明细见 [`gateway-api.md`](gateway-api.md) |

| **agent 配置** | `agent-profiles/v2/config`，191 个文件 | `assets/agent-profiles/v2/config` | **原样** | 逐字相同；只多一份 `knowledge/vendors/platform-routing.md` 说明各模态落到平台的哪个模型 |
| **技能** | `~/.hub/skills`，36 个 | `assets/skills`，启动时铺到 `~/.ovhub/skills` | **原样** | 逐字相同；技能市场接口直接列这 36 个 |
| **opencode 本体** | 1.18.18（MIT 开源） | 同版本 | **原样** | 一致（开发时借用本机参照应用里的二进制，打包时要随包带） |

| 自定义模型 | 有 | 没有 | 不做 | 2026-09-26 用户定为范围外；入口待隐藏 |
| 打包、自动更新（Velopack） | 有 | 没有 | 未做 | M10 |

## 二、按"用户看得到的功能"看

| 功能 | 状态 | 说明 |
|---|---|---|
| 首页、项目库、项目详情、设置、技能页 | 可用 | 参照界面原样，品牌已换 |
| 多工作区、侧栏最近项目、悬停预览 | 可用 | 预览走页面内浮层（参照在有内置浏览器时用原生浮层） |
| 画布（节点、标签、分组、缩略图） | 可用 | 界面原样；后端路由已补齐画布这一块 |
| 对话 → agent 生成图片 → 落到画布 | **已在真平台走通** | 2026-09-26 在参照界面里验过 |
| 出图 | 走平台聚合模型 `qwen-image-pro-enhanced`（提示词改写 + 自动定画幅） | 比例选"自适应"时由平台定画幅 |
| 视频 / 音乐 / 语音生成 | 后端已做，未在参照界面里逐个验 | 语音只能用参考音频零样本克隆，平台没有预设音色 |
| 编辑类 | 大部分可用 | 扩图 / 重绘 / 擦除 / 移动物体用 qwen-image-pro，画质增强和视频超分用 swiftvr；语音识别、抠图、口型、擦字幕、音频分离、图层拆分平台没有，界面提示"当前平台不支持" |
| 项目导入导出、示例项目 | 可用 | 格式与参照一致，参照导出的项目包也能导入 |
| 文件面板、@ 提及、视频播放、文本版本历史、记忆管理、全局搜索、会话导出 | 可用 | 2026-09-26 补齐 |
| 桌面软件连接器、代理模式生效 | 未做 | 自定义 MCP 的热加载 gateway 侧已做 |
| 登录、团队、计费、ComfyUI、内置浏览器、自定义模型 | 不做 | 范围外 |
