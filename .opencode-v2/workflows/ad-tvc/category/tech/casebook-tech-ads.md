# 3C数码广告案例库 — Casebook

> **何时读**：锚点阶段按 3C 品类卡的条件挑路线母题时才打开；分镜、视频生成、后期都不读。
> **怎么用**：这是母题参考，不是必走流程。锚点阶段把选中的案例改写成 `video_creative_route`，最终用哪些技法仍由技法目录决定并写进 `technique_plan`。
> **只留方法**：案例里只有可复用的做法，不含具体视频文件路径；用户给的参考片以调研 capsule 里保存的风格要点为准。

---

## 使用方法

1. 看产品类型、主打卖点和品牌气质，挑最贴近的一个案例，把视觉母题、段落结构和案例编号写进 `video_creative_route`。
2. 案例里列的技法只是候选，交给 `visual-techniques-library.md` 去筛；最后选中的技法写进 `technique_plan`。
3. 分镜只认锚点 `constraints` 里绑定的案例和 `technique_plan`；视频生成和后期不会来读案例，也不会自行加技法。

## Case 01 — 透明工业设计 / Lo-Fi High-Tech

| 维度 | 说明 |
|---|---|
| 合适的产品 | 透明壳耳机、个性手机、极客硬件、带灯带或点阵灯语的设备 |
| 画面特征 | 大面积黑白灰，只留一处品牌色；壳体透明或半透，看得见里面的零件；点阵字体；取景框式 HUD；材质近景快速拼接 |
| 为什么有效 | 把“工程样机感”“说明书感”“极客范”变成品牌审美 |
| 候选技法 | T05、T06、T08、T10、T11、T14 |
| 段落参考 | 暗场或极简空间里的产品剪影 → 透明壳与内部结构近景 → 说明书式的部件 / 参数版面 → 点阵 Logo 或网址收尾 |
| 注意 | 那唯一的品牌色要落在产品最有辨识度的部件上；HUD 和点阵字属于构图，不许盖住重要结构 |

### Anchors 路线落地提示

- 在路线里记 `Case 01 / Lo-Fi High-Tech`；技法交给目录去筛。
- 分镜里至少安排三处部件近景，可从接口、按键、转轴、防尘网、透明壳、内部元件中选。
- 出现文字时，优先把它当版面元素排进画面，而不是做成底部字幕。

## Case 02 — 声学配件 / 形态同构与液体声波

| 维度 | 说明 |
|---|---|
| 合适的产品 | 真无线耳机、头戴耳机、音箱、降噪设备、轻便穿戴设备 |
| 画面特征 | 抽象几何慢慢变成产品；液面泛起涟漪或液滴悬浮；一圈圈波纹；物体弹跳踩着节拍；人体线稿贴合佩戴；多配色一起亮相 |
| 为什么有效 | 借形状和物理现象讲清楚音质、降噪、戴着舒服、年轻好玩 |
| 候选技法 | T10、T15、T16、T18 |
| 段落参考 | 圆、球、波纹这类抽象形状 → 形状化为产品 → 产品碰到液面或波纹 → 线稿演示如何贴合耳朵 / 头部 → 多色产品同框定格 |
| 注意 | 液体必须在说声音、降噪或轻盈，不能只是好看的水；弹跳动作要踩准音乐重拍 |

### Anchors 路线落地提示

- 在路线里记 `Case 02 / Acoustic Morph`；技法交给目录去筛。
- 产品的核心几何形状要在开头以抽象形态先出现，再变回真实产品。
- 线稿人体只画简单外形，比如耳朵、手腕或侧脸，不建议安排复杂的真人表演。

## Case 03 — 高性能设备 / 表里透视科技链

| 维度 | 说明 |
|---|---|
| 合适的产品 | AI 电脑、电竞本、性能笔记本、生产力平板、主打芯片或显卡算力的设备 |
| 画面特征 | 从外壳材质一路深入到内部芯片，再到屏幕里的应用、交互细节，最后是产品主画面；用光的流动表示算力；冷色、暖色把场景分成两半 |
| 为什么有效 | 从外到内一层层看进去，让人信服技术；用色温把“拼性能”和“日常好用”分开讲 |
| 候选技法 | T03、T05、T07、T10、T17 |
| 段落参考 | 场景中的人或产品剪影 → 外观与接口近景 → 主板、芯片、散热、光流 → 屏幕上的应用或游戏 → 指纹识别、摄像头遮挡、开机键之类的操作细节 → 带卖点文案的收尾画面 |
| 注意 | 性能尽量用视觉比喻表达；真要出现具体数字，必须来自厂商公开资料，并带上合规说明 |

### Anchors 路线落地提示

- 在路线里记 `Case 03 / Inside-Out Tech Chain`；技法交给目录去筛。
- 偏冷的段落交代跑分、游戏、计算能力；偏暖的段落交代办公、创作、手感与日常。
- 操作细节不少于两处，比如插口、指纹区、开机键、摄像头挡片、键盘、镜头模组。

## 选型速查

- 看得见内部、主打极客潮流 → Case 01；技法先看 T05、T08、T10、T14。
- 耳机音箱、降噪、戴着轻 → Case 02；技法先看 T10、T15、T16、T18。
- AI 电脑、性能本、讲芯片算力 → Case 03；技法先看 T05、T10、T03、T17。
- 多台设备互联 → Case 01 加上 tech 卡的联动段；技法先看 T05、T06、T14。
- 同款多种颜色 → Case 02；技法先看 T10、T18。
- 游戏办公两头都要 → Case 03；技法先看 T03、T17。
