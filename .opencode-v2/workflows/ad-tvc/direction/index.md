# TVC Direction 索引

按需求简报里定下的广告类型挑一张卡，不要整目录读。视觉调研阶段用卡里的 `creative-research` 节；锚点、分镜阶段各用与自己同名的节。

- `brand-ad` → `<workflowsDir>/ad-tvc/direction/brand-ad.md`：想让人记住品牌的价值观、气质或情绪，追求长线印象。
- `product-ad` → `<workflowsDir>/ad-tvc/direction/product-ad.md`：要把产品的样子、用料、功能或卖点拍明白。
- `story-ad` → `<workflowsDir>/ad-tvc/direction/story-ad.md`：靠一个人（或一个主体）的变化讲一段有头有尾的故事。
- `viral-ad` → `<workflowsDir>/ad-tvc/direction/viral-ad.md`：靠反转、爆点或值得转发的事件扩散。

用户已经说清类型就直接用；只有几个目标互相打架、而且会改变整片结构时，才请用户二选一。
