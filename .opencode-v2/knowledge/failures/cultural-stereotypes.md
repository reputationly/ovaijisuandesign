# cultural-stereotypes -- vague culture labels

## Activate When
A broad culture word arrives with nothing that pins region, period, social setting, medium or purpose.

## Decision Test
Could the label reasonably point to three or more distinct visual traditions? Then ask. If the user's words or refs already fix the sub-tradition, adopt it, name it, and keep unrelated clichés out.

## Action
- Ask along axes rather than offering a fixed menu: period, region, social layer, source medium, where the image will be used.
- Only add exclusions for clichés the user did not ask for.
- When the user does want a cliché element, keep it and make everything around it more precise.

## Calibration
"Japanese" might mean Edo woodblock, Showa-era advertising, 90s anime cels or quiet Muji-like minimalism; treat such lists as prompts for thought, not limits.
