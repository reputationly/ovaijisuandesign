# mood-vocabulary -- mood words with many readings

## Activate When
The user gives a broad mood or taste word that could support several clearly different looks.

## Decision Test
If you can think of three treatments that differ in material, density, color intent or period, ask. If refs anchor the mood, name the non-color anchor; put palette into text only when the user named it or approved it.

## Action
- Ask by axes, not labels: richness of materials, amount of empty space, saturation, period, a companion object, medium.
- When two mood words pull against each other, ask which one wins.
- Once decided, turn the mood into levers the model can render: light quality, texture, how crowded the frame is, lettering tone, and only the approved palette.

## Calibration
"Premium" can be black-and-gold luxury, white gallery minimalism or warm walnut craft; such examples are samples, never defaults.
