# Poster Image Recipe

## Activate When
`hub_select_image_recipe` 返回 `recipe_id` 为 `poster` 时读本卡：一张独立的海报、主视觉 KV、活动或节日海报、促销海报、餐饮饮料海报、美妆海报、新品海报、招聘/课程/公益海报、演出海报、影视海报。

读完直接写一条 `hub_generate_image` 的 prompt。海报任务留在直接路径上，不交给 planner，不写 Stage Execution Plan。

## Decision Test
- 交付物是单张图，或几张彼此独立、现在就能出的海报版本 → 适用。
- 修改已有海报：把原图放进 `image_paths`，按同样思路写编辑 prompt，用户说要保留的构图、主角和文案都不动。
- 需要多镜头视频、先做角色/场景等依赖资产、或要长脚本规划的任务 → 不适用，走对应工作流。

## Core Rule
图像模型本身就懂海报长什么样。本卡的作用是把用户的原话留住，只补几处模型容易拿不准的确定信息；不要把 brief 扩写成设计说明书。

先后顺序：
1. 用户给的东西一个不丢：品类、文案、主体、品牌或平台名、颜色、尺寸、构图、气氛、信息主次。
2. 再补确定的视觉控制：画幅方向、投放场景、颜色占比、明暗关系、一个宽泛的版式方向、文字之间的层级。
3. 只有主体明确需要质感时（玻璃杯、护肤品、食物），加一句材质和光的描述。

用户没提供的商业信息——价格、优惠条款、二维码、电话、地址、承诺、人物、地点、故事——留空或用中性占位，不要编。用户没说要排除的东西，也不要写成否定句。

用户自己写出的品牌名、平台名、活动名是要清楚显示的文字，照写。需要回避的只是用户没给素材的 logo 图形和真实商品包装上的商标外观。

颜色占比最值得补：用户给了配色或情绪时，结尾写成大致比例，例如主色约六到七成、辅助色两到三成、点缀高光不到一成，再说明亮部落在哪里、主体和文字的明暗对比如何。这一步不算过度设计。

## Prompt Assembly
prompt 直接从画面写起，不加"海报说明"之类的标题。结构是"用户原话段 + 补充尾句"：

1. **Original brief paragraph**：第一段尽量保留用户的语序、口气和那些模糊但有用的说法（"热闹一点""多放几样""字要显眼"），这些词能调动模型已有的品类经验。
2. **Enhancement tail**：尾部只加画幅、颜色占比、明暗、一句安全说明或一句文字排布说明。不要把用户的文案再抄一遍，不要把版面拆成一格一格的位置清单。
3. **Sparse brief handling**：用户说得很少时只补视觉方向；缺的信息如果会改变商业含义，就问用户或留中性占位。

## What To Add
下列每项最多一句，而且只在条件成立时加：

| 补充项 | 触发条件 | 写到什么程度 |
|---|---|---|
| 画幅 | 用户给了尺寸、平台、横竖，或没说清 | "竖版 9:16，手机全屏观感"；同时在 `vendor_params.aspect_ratio` 里给同样的比例 |
| 投放场景 | 提到主会场、门店、易拉宝、朋友圈等 | "门店橱窗海报" / "手机端首屏主视觉" |
| 颜色关系 | 用户给了颜色或情绪 | 必须写大致占比和明暗主次 |
| 版式方向 | 没说结构但需要一个基本骨架 | 只给一个词：上图下文 / 居中对称 / 大面积留白 / 分区陈列 / 信息逐级递减 |
| 文字层级 | 文案多、有时间/按钮/卖点等层级 | 一句"文字主次分明、疏密得当" |
| 品牌安全 | 用户要求去 logo，或画面出现第三方具体商品 | 用无品牌的通用商品和抽象包装；用户写出的品牌文字照留 |
| 材质光线 | 冷饮、玻璃、化妆品、食物、包装等主体 | 两到四个质感词，如水珠、透光、投影、轮廓高光 |

## Boundaries
- 细节排布交给模型，prompt 只保留用户要的结构和一个宽泛版式方向。
- 商业事实只来自用户；没有就留中性占位或问。
- 文字质量用一句短话兜住，不写成排版规范或校对清单。平台图像模型对长段落和密集小字不稳定：文案很多时先和用户商量精简。
- 安全说明默认不写，只在用户要求或确有商标风险时加一句。
- 品类经验只给方向词，模型知道电商、咖啡、美妆、招聘、演出、电影海报常见的样子。
- 分辨率：有小字时用 `2K`，否则 `1K` 即可。

## Category Hints
只在 brief 很单薄、需要一个稳定方向时参考，完整 brief 不必看：

- 电商大促：画幅、颜色占比、节日感的明暗，商品用无品牌通用款。
- 餐饮饮品：产品特写做主角，强调食欲或冰爽质感，文字像菜单或包装。
- 美妆个护：产品居中、大留白或细边框，玻璃、金属、膏体、水滴的质感。
- 新品发布：产品剪影清晰，表面反光和边缘光。
- 节日活动：有仪式感的构图，主色定气氛，活动名清楚。
- 招聘、课程、公益：文字为主，网格清楚。
- 音乐演出：舞台灯、逆光轮廓、动感。
- 影视海报：按题材选一种常见的电影海报构图。

## Before Generation
自查：prompt 的主体仍是用户的话；补充的都是确定信息；价格、优惠等事实要么是用户给的、要么留了空；安全说明不超过一句；整条读起来像一段能直接执行的海报 brief。
